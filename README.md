# Adversarial Deconfounding Autoencoder for Learning Robust Gene Expression Embeddings

### Ayse B. Dincer

##### Paul G. Allen School of Computer Science & Engineering, University of Washington, Seattle

We introduce the AD-AE (Adversarial Deconfounding AutoEncoder) approach to deconfound the gene expression latent spaces. The AD-AE model consists of two neural networks: (i) an autoencoder to generate an embedding that can successfully reconstruct the original measurements and (ii) an adversary that is trained to predict the confounder from the embedding. The idea is to jointly train the networks to generate embeddings that can encode as much information as possible while not being able to predict the confounders. By applying AD-AE to two distinct gene expression datasets, we show that our model can (1) generate embeddings that do not encode confounder information, (2) conserve the biological signals present in the original space, and (3) generalize successfully across different confounder domains. We demonstrate that AD-AE can outperform standard autoencoder as well as other deconfounding approaches.

### Adversarial Deconfounding Autoencoder Pipeline

**KMPLOT_BRCA_EXPRESSION** and **TCGA_BRAIN_EXPRESSION** folders contain the scripts for repeating the experiments on the two different datasets, respectively.

---
#### Experiments on Breast Cancer Expression

**1.  Data Files**

The **DATA** folder contains the expression and phenotype datasets.  

**KMPLOT_BRCA_SURVIVAL.txt** is the expression matrix, **KMPLOT_BRCA_SURVIVAL.txt** contains the phenotype labels, such as dataset 
and ER labels, and **probeSetsToGenes.txt** is the dictionary to map probe ids to gene names.

**2.  Preprocessing Data**

**a.** As the first step, we preprocess the expression matrix using the notebook **Preprocess_Expression_Data.ipynb**.  
**b.** We then select a subset of datasets and apply k-means clustering, following **Select_Expression_Datasets.ipynb**.  
**c.** We extract the dataset labels with **Extract_Dataset_Labels.ipynb**.  

**3. Motivating Example**

The **A_MOTIVATING_EXAMPLE** folder contains all scripts for the confounder case example.  
**a.** **Autoencoder.ipynb** selects two example datasets, trains a standard autoencoder, and creates embeddings.  
**b.** **Create_PC_Plots.ipynb** generates the principal component plots for the expression matrices and the autoencoder embeddings.  
**c.** **Calculate_Correlations.ipynb** measures the correlation between the embedding values and dataset labels.  

**4. Autoencoder Hyperparameter Selections**

The **MODEL_TUNINGS** folder contains the scripts to tune parameters of autoencoder models with different latent dimensions.

**5. AD-AE Trainings**

**a.**  **Adversarial_Deconfounding_AE_Model_Selection.ipynb** trains AD-AE models and tunes the number of epochs to optimize the models.  
**b.** **Adversarial_Deconfounder_AE_Generate_Embeddings.py** trains AD-AE model and records the embeddings.  
**ADV_FILES** folder contains all the model and embedding files generated by AD-AE.
The embeddings generated by training from all five datasets are in ALL_DATASETS folder and 
the embeddings generated by leaving out the fifth dataset are all in 100L_ALL_DATASETS_EXCEPT_5. Similarly the folders for the different dimensional embeddings are included.

**6. Creating 2D Plots**

Folder **CREATE_2D_PLOTS** contains all scripts to generate PC and UMAP plots of the embeddings, including the joined plots for the transfer experiments.

**7. Training Competitors**

Folder **COMPETITORS** contains the scripts to train the competitor models and generate embeddings.  
**COMBAT** contains **Preprocess_Data.ipynb** to preprocess expression before applying correction, 
**Apply_Combat.R** to apply Combat, and **Standard_Autoencoder_One_Dataset_Excluded.ipynb** 
to train standard autoencoder on the corrected data and generate embeddings.

**GENE_MEAN** contains **Mean_Center_Genes.ipynb** to standardize the expression and  **Standard_Autoencoder_One_Dataset_Excluded.ipynb**  to train autoencoder.  
**GENE_STD** contains **Standardize_Genes.ipynb** to standardize the expression and  **Standard_Autoencoder_One_Dataset_Excluded.ipynb**  to train autoencoder.  
**NO_CORRECTION** contains **Standard_Autoencoder.ipynb** to train a vanilla autoencoder with no correction from all datasets and 
**Standard_Autoencoder_One_Dataset_Excluded.ipynb** to train by leaving the fifth dataset out.  

**8. Prediction Models**

**PREDICTIONS** folder contains the scripts to predict the phenotypes from the embeddings and generate the prediction plots.

---
#### Experiments on Brain Cancer Expression

**1.  Data Files**

The **DATA** folder contains the expression and phenotype datasets.  
**tcgadata_final_LGG.tsv** and **tcgadata_final_GBM.tsv** are the expression matrices, 
**LGG.clin.merged.picked.txt** and **GBM.clin.merged.picked.txt** contains the clinical labels.

**2.  Preprocessing Data**

**a.** As the first step, we preprocess the expression matrix using the notebook **Preprocess_TCGA_Expression.ipynb**.  
**b.** We extract the dataset labels with **Preprocess_Labels.ipynb**.  

**3. AD-AE Trainings**

**a.**  **Tune_Autoencoder_Model.ipynb** carries hyperparameter tunings.  
**b.** **Adversarial_Deconfounding_AE_Sex_Model_Selection.ipynb** trains AD-AE models with the sex as the confounder 
and tunes the number of epochs to optimize the models. **Adversarial_Deconfounding_AE_Generate_Embeddings_Sex.py**  
trains AD-AE model with sex confounder and records the embeddings. **ADV_FILES_SEX** folder contains all the models and embeddings.  
**c.** **Adversarial_Deconfounding_AE_Age_Model_Selection.ipynb** trains AD-AE models with the age as the confounder 
and tunes the number of epochs to optimize the models. **Adversarial_Deconfounding_AE_Generate_Embeddings_Age.py**  
trains AD-AE model with age confounder and records the embeddings. **ADV_FILES_AGE** folder contains all the models and embeddings.  

**4. Training Competitors**

Folder **COMPETITORS** contain the scripts to train the competitor models and generate embeddings, 
following the same procedure as applied for the breast cancer expression.  

**5. Prediction Models**

**PREDICTIONS** folder contains the scripts to predict the phenotypes from the embeddings and generate the prediction plots.
